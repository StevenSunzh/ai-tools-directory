# AI Agents & MCP

A directory of AI agent frameworks, MCP servers, and workflow tools.
Full interactive directory: [aikit.vip](https://aikit.vip/).

## Agent Frameworks

| Framework | What it does |
|-----------|-------------|
| LangChain | LLM application framework |
| LangGraph | Stateful agent orchestration |
| AutoGen | Multi-agent conversation framework |
| CrewAI | Role-based agent teams |
| OpenClaw | Personal AI assistant framework |

## MCP Servers & Tools

| Project | What it does |
|---------|-------------|
| Model Context Protocol (MCP) | Standard for connecting AI to tools/data |
| mcp-servers | Community MCP server collection |
| Claude Skills | Reusable capability packs for Claude |

## Workflow & Automation

| Tool | What it does |
|------|-------------|
| n8n | Workflow automation with AI nodes |
| Zapier | No-code automation |
| Dify | LLM app development platform |
| Coze | Agent building platform |
