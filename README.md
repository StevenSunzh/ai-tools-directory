# AI Tools Directory

A curated, categorized directory of AI tools, agents, and open-source
projects, maintained at [aikit.vip](https://aikit.vip/).

## What it covers

- **AI tools** — chatbots, coding assistants, image/video generators, productivity apps
- **AI agents & MCP** — agent frameworks, MCP servers, and workflow tools
- **Open-source projects** — trending repos with weekly analysis
- **AI news** — model releases, agent frameworks, and industry shifts

## Structure

- `categories/` — tool listings by category
- `agents/` — agent and MCP server entries
- `open-source/` — open-source project notes
- `news/` — weekly AI news digest

## Contribute

Submit a tool or project by opening an issue or pull request.
